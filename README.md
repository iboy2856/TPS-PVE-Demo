# Unity 3D PVE 射击游戏求职项目

本项目是一个第三人称射击（TPS）游戏 Demo，展示了从角色控制到战斗系统的完整实现。项目持续迭代中，所有代码均有 Git 记录。

## 已完成功能

### 玩家系统
- 第三人称角色移动（基于相机方向，WASD 控制）
- 相机系统：轨道模式 + 肩射模式平滑切换，无延迟不穿模
- 玩家生命值系统（受伤无敌帧、死亡逻辑）
- UI：弹药显示（当前/后备）、生命值血条

### 射击系统
- 手枪射击（射线检测命中准星，支持精准瞄准）
- 对象池管理子弹、弹壳、枪口火焰（避免频繁 GC）
- 弹药系统（弹匣容量、后备弹药、换弹功能）
- 后坐力效果（手部抖动）、枪口特效、开火/空枪音效

### 敌人 AI（丧尸）
- 抽象基类设计（`ZombieBase`），子类实现不同行为
- 普通丧尸（30血，10伤害）和坦克丧尸（100血，25伤害+击退）
- 移动逻辑（向玩家移动，攻击范围内停止）
- 攻击冷却 + 攻击判定窗口（伤害与动画同步）
- 受击反馈、死亡销毁

### 动画系统
- 基础移动动画（Idle/Walk/Run 由 Speed 参数控制）
- 瞄准层动画（`AimingLayer` + Avatar Mask，实现上半身持枪）
- 丧尸攻击动画（Trigger 触发 + Has Exit Time 自动返回）

### 技术亮点
- 对象池（BulletPool）优化性能
- 射线检测精准命中 + LayerMask 忽略玩家自身
- 抽象类 + 继承实现丧尸类型扩展
- Git 版本管理，提交记录清晰

## 开发环境
- Unity 版本：2021.3.x（或 2022.3.x）
- 语言：C#

## 如何运行
1. 克隆本仓库
2. 用 Unity Hub 打开项目文件夹
3. 打开 `Assets/Scenes/SampleScene`（或主场景）
4. 点击运行，WASD 移动，鼠标旋转视角，左键射击，右键瞄准，R 换弹
